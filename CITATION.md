# Citation

Please cite the associated driving-evaluation manuscript when using this code
or its synthetic examples. Publication-specific citation metadata can be added
when the final manuscript reference is available.

The synthesis implementation builds on:

- Shi et al. (2025), *TabDiff: a Mixed-type Diffusion Model for Tabular Data
  Generation*, ICLR. https://openreview.net/forum?id=swvURjrt8z
- Karras et al. (2022), *Elucidating the Design Space of Diffusion-Based
  Generative Models*, NeurIPS. https://arxiv.org/abs/2206.00364
